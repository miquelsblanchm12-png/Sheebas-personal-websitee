# SHEBAS — Personal Portfolio

A personal portfolio website created to introduce myself, showcase my projects, and share things I'm working on.

This is one of my first projects and a way for me to experiment with web development, design and new technologies.

## About

I'm Shebas, a young developer interested in technology, programming and building things.

I created this website as my personal space on the web, where I can show what I'm learning and the projects I'm working on.

## Features

- Personal introduction
- About me section
- Project showcase
- StudyOS project page
- Personal Vlog
- Responsive design
- Interactive ASCII cube
- Shared visual identity across pages
- Dark technological background
