AI was an important part of the development process, but my goal wasn't to simply ask AI to create the entire website for me.

I asked AI to help me:

- Understand HTML and CSS concepts
- Learn JavaScript
- Explain code I didn't understand
- Debug problems
- Find mistakes in my code
- Understand responsive design
- Improve the structure of my website
- Experiment with different design ideas
- Understand JavaScript Canvas
- Learn about basic 3D mathematics
- Generate ideas for the project
- Create visual concepts and backgrounds

Whenever I received code that I didn't understand, I could ask for an explanation and then modify it myself.

### 🧠 AI as a Learning Tool

One of the main goals of this project was to learn coding by actually building something.

Instead of only watching tutorials, I could build something, encounter a problem, ask AI about it, understand the explanation and then continue working.

For me, AI worked more like a **teacher and coding assistant** rather than something that replaces learning.

## 🧊 Interactive ASCII Cube

One of the most interesting parts of the website is the interactive ASCII 3D cube.

The cube is rendered using the HTML `<canvas>` element and JavaScript.

It uses concepts such as:

- 3D coordinates
- X, Y and Z axes
- Rotation
- Perspective projection
- Depth
- Canvas rendering
- Mouse interaction

I used AI to help me understand these concepts and how they could be implemented with JavaScript.

The cube can rotate automatically and also reacts to the user's mouse movement.

This was one of the parts of the project that helped me understand JavaScript beyond simple buttons and interactions.

## 🎨 Design

I wanted the website to have a:

**Minimal · Calm · Technological**

visual style.

The design uses:

- Dark backgrounds
- Large typography
- Minimal navigation
- Thin borders
- Subtle transparency
- Simple layouts
- Monochrome / dark colors
- Responsive sections

I also used AI image-generation tools to experiment with the visual direction and create the technological background used throughout the website.

The goal was to keep the design interesting without adding unnecessary animations or effects.

---

## 📱 Responsive Design

The website is designed to work on different screen sizes.

I used CSS media queries to adapt:

- Navigation
- Typography
- Project cards
- Spacing
- Layouts

The project grid, for example, changes from multiple columns on desktop to a single column on smaller screens.
